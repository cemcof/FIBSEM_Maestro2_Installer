# FIBSEM Maestro Installer

Installs, updates, repairs and uninstalls [FIBSEM Maestro](https://github.com/Ladme/FIBSEM_Maestro) for the current user.

## Usage

Download `fibsem-maestro-installer-windows-x86_64.exe` or `fibsem-maestro-installer-linux-x86_64` from the [releases](../../releases) and run it.

The installer sets up its own Python and environment in `%LOCALAPPDATA%\FibsemMaestro` (Windows) or `~/.local/share/fibsem-maestro` (Linux), and creates a Start Menu / desktop entry.

Microscope libraries (e.g. Thermo Fisher Autoscript) are not distributed with FIBSEM Maestro. Linking them is optional and can be done or changed later by running the installer again.
